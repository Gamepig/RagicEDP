## 一、格式驗證規則 (Format Validation Rules)

### FMT-001: 台灣手機號碼格式

| 項目 | 內容 |
|------|------|
| **規則 ID** | FMT-001 |
| **適用表格** | 60_客戶表, 50_訂單表, 99_訂單明細表 |
| **適用欄位** | 行動電話, 收件人電話 |
| **驗證正則** | `^09\d{8}$` |
| **描述** | 台灣手機號碼應為 10 位數字，以 09 開頭 |
| **錯誤處理** | 標記為格式異常，需人工確認 |
| **歷史有效率** | 99.24% (客戶), 98.41% (訂單) |

**變體正則**（允許格式）：
```regex
# 標準格式
^09\d{8}$

# 含連字號格式
^09\d{2}-\d{3}-\d{3}$

# 國際格式
^\+?886\d{9,10}$
```

**已知特殊情況**：
- `平台資料隱蔽`：平台訂單，電話被隱藏
- 含分機號：如 `02-6636-6369#1825`
- 多號碼：如 `0928000888,04443177#1`
