### FMT-002-FIX: 市話缺碼自動修正 ⭐ NEW

| 項目 | 內容 |
|------|------|
| **規則 ID** | FMT-002-FIX |
| **適用表格** | 60_客戶表 |
| **適用欄位** | 行動電話（實際存放市話的情況）|
| **類型** | 自動修正 (Auto-Fix) |
| **狀態** | ✅ 已實作於 `scripts/fix_phone_format.py` |

**問題描述**：
部分客戶的「行動電話」欄位實際存放的是市話號碼，且缺少開頭的 `0`。

**判斷邏輯**：

| 原始格式 | 判斷條件 | 修正結果 | 區域 |
|----------|----------|----------|------|
| `2xxxxxxxx` | 2 開頭 + 9 碼 | `02xxxxxxxx` | 台北/新北/基隆 |
| `3xxxxxxx` | 3 開頭 + 8 碼 | `03xxxxxxx` | 桃園/新竹/宜蘭/花蓮 |
| `4xxxxxxx` | 4 開頭 + 8 碼 | `04xxxxxxx` | 台中/彰化/南投 |
| `5xxxxxxx` | 5 開頭 + 8 碼 | `05xxxxxxx` | 雲林/嘉義 |
| `6xxxxxxx` | 6 開頭 + 8 碼 | `06xxxxxxx` | 台南 |
| `7xxxxxxx` | 7 開頭 + 8 碼 | `07xxxxxxx` | 高雄 |
| `8xxxxxxx` | 8 開頭 + 8 碼 | `08xxxxxxx` | 屏東/台東/澎湖 |

**台灣市話區碼規則**：

```
區碼    區域                    完整格式
02      台北/新北/基隆          02 + 8碼 = 10碼
03      桃園/新竹/宜蘭/花蓮     03 + 7碼 = 9碼
04      台中/彰化/南投          04 + 7-8碼 = 9-10碼
05      雲林/嘉義               05 + 7碼 = 9碼
06      台南                    06 + 7碼 = 9碼
07      高雄                    07 + 7碼 = 9碼
08      屏東/台東/澎湖          08 + 7碼 = 9碼
037     苗栗                    037 + 6碼 = 9碼
049     南投                    049 + 6碼 = 9碼
089     台東                    089 + 6碼 = 9碼
```

**實作程式碼**：

```python
def analyze_phone(phone: str) -> Tuple[str, Optional[str], Optional[str]]:
    """
    分析電話號碼並判斷是否需要修正

    Returns:
        (類型, 修正後號碼, 說明)
        類型: 'mobile' | 'landline' | 'landline_missing_0' | 'unknown'
    """
    digits = re.sub(r'[^\d]', '', str(phone))

    # 2 開頭 + 9 碼 → 台北市話缺少 0
    if digits.startswith('2') and len(digits) == 9:
        return ('landline_missing_0', '0' + digits, f'台北市話缺少 0')

    # 3-8 開頭 + 8 碼 → 其他縣市市話缺少 0
    if digits[0] in '345678' and len(digits) == 8:
        return ('landline_missing_0', '0' + digits, f'0{digits[0]} 區市話缺少 0')

    return ('unknown', None, '格式不明')
```
