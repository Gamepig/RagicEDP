## 三、資料清理觀點

### 3.1 現有問題

| 問題 | 說明 | 影響 | 嚴重度 |
|------|------|------|:------:|
| 60 缺品牌欄位 | 結構上無法識別客戶歸屬品牌 | 無法在清理階段標記客戶歸屬 | ⚠️ 中 |
| 資料順序顛倒 | 60 應從 99 歸納，但實際先輸入 60 | 可能產生孤立客戶記錄 | ⚠️ 中 |
| 99 是寬表 | 冗餘欄位多（93 欄） | 清理規則需對應多來源 | 🔵 低 |

### 3.2 清理策略建議

**方案：清理時補充品牌維度**

```
60 客戶表 ──清理──→ 60' 客戶表（含推導品牌）
                         ↑
                    從 99 推導
                    （99.13% 準確率）
```

**執行步驟**：

| 步驟 | 說明 |
|:----:|------|
| 1 | 清理 99 訂單明細（以 99 為主要事實來源） |
| 2 | 從 99 統計每位客戶的「主要品牌」 |
| 3 | 將推導的品牌寫入清理後的 60 表 |
| 4 | 標記跨品牌客戶（0.87%）特別旗標 |

### 5.1 優先級排序

| 優先級 | 面向 | 建議 |
|:------:|------|------|
| 🔴 高 | 資料清理 | 清理時從 99 推導客戶品牌，補充至 60 |
| 🔴 高 | 行銷分析 | 建立「客戶-品牌」對應 View |
| ⚠️ 中 | 資料清理 | 標記跨品牌客戶（特殊處理） |
| ⚠️ 中 | 行銷分析 | 識別跨品牌客戶作為特殊分析群體 |
| 🔵 低 | 資料清理 | 處理「60 有記錄但 99 無訂單」的客戶 |

### 5.2 實作建議

**BigQuery View 範例**：

```sql
-- 客戶品牌歸屬 View
CREATE OR REPLACE VIEW `erp_backup.view_customer_brand` AS
WITH customer_brand_stats AS (
    SELECT
        customer_code,
        brand_code,
        COUNT(*) as order_count,
        SUM(amount) as total_amount,
        ROW_NUMBER() OVER (
            PARTITION BY customer_code
            ORDER BY COUNT(*) DESC
        ) as brand_rank
    FROM `erp_backup.sheet_99_order_detail`
    WHERE customer_code IS NOT NULL
    GROUP BY customer_code, brand_code
)
SELECT
    customer_code,
    MAX(CASE WHEN brand_rank = 1 THEN brand_code END) as primary_brand,
    COUNT(DISTINCT brand_code) as brand_count,
    CASE
        WHEN COUNT(DISTINCT brand_code) > 1 THEN TRUE
        ELSE FALSE
    END as is_multi_brand
FROM customer_brand_stats
GROUP BY customer_code;
```

## 八、客戶品牌關聯 View（建議方案）

### 8.1 背景說明

60 客戶表沒有品牌欄位，但分析時需要「按品牌分析客戶」。

**問題**：是否在 60 表新增品牌欄位？

**結論**：不建議。因為：
- 0.87% 客戶購買多品牌（346 人）
- 單一欄位存多值會導致查詢、聚合、JOIN 困難
- 違反資料庫第一範式

**建議方案**：建立「客戶-品牌關聯 View」，透過 99 訂單明細動態計算。

### 8.2 單一欄位存多品牌的問題

若在 60 表品牌欄位輸入 "GMK、YAS"，會產生以下問題：

| 問題 | 說明 |
|------|------|
| 查詢困難 | `WHERE brand = 'GMK'` 無法匹配 "GMK、YAS" |
| 聚合錯誤 | `GROUP BY brand` 會把 "GMK、YAS" 當成獨立品牌 |
| JOIN 失效 | 無法與品牌表正確 JOIN |
| 格式不一致 | "GMK、YAS" vs "GMK,YAS" vs "GMK/YAS" |
| 違反第一範式 | 一個欄位應只存一個值 |

### 8.3 關聯模型

```
60 客戶表（不放品牌）     客戶品牌關聯 View          10 品牌表
┌─────────────┐          ┌─────────────────┐        ┌───────────┐
│ 客戶編號 PK │ ←──1:N──→│ 客戶編號        │        │ 品牌編號 PK│
│ 客戶名稱    │          │ 品牌編號        │←──N:1─→│ 品牌名稱  │
│ 電話        │          │ 訂單數          │        └───────────┘
│ ...         │          │ 購買金額        │
└─────────────┘          │ 首次購買日期    │
                         │ 最後購買日期    │
                         │ 是否為主要品牌  │
                         └─────────────────┘
```

### 8.4 BigQuery View 建立語法

#### View 1：客戶品牌關聯明細

```sql
-- 建立客戶品牌關聯 View
-- 每位客戶對每個品牌的購買統計
CREATE OR REPLACE VIEW `b25h01-ragic.erp_backup.view_customer_brand` AS
WITH customer_brand_stats AS (
    SELECT
        JSON_VALUE(data, '$.客戶編號') AS customer_code,
        JSON_VALUE(data, '$.品牌編號') AS brand_code,
        COUNT(DISTINCT JSON_VALUE(data, '$.訂單編號')) AS order_count,
        COUNT(*) AS item_count,
        SUM(CAST(JSON_VALUE(data, '$.商品常態售價小計') AS FLOAT64)) AS total_amount,
        MIN(JSON_VALUE(data, '$.訂單成立日期')) AS first_purchase_date,
        MAX(JSON_VALUE(data, '$.訂單成立日期')) AS last_purchase_date
    FROM `b25h01-ragic.erp_backup.sheet_99_order_detail`
    WHERE JSON_VALUE(data, '$.客戶編號') IS NOT NULL
      AND JSON_VALUE(data, '$.客戶編號') != ''
      AND JSON_VALUE(data, '$.品牌編號') IS NOT NULL
    GROUP BY customer_code, brand_code
),
ranked AS (
    SELECT
        *,
        ROW_NUMBER() OVER (
            PARTITION BY customer_code
            ORDER BY order_count DESC, total_amount DESC
        ) AS brand_rank,
        COUNT(*) OVER (PARTITION BY customer_code) AS total_brands
    FROM customer_brand_stats
)
SELECT
    customer_code,
    brand_code,
    order_count,
    item_count,
    total_amount,
    first_purchase_date,
    last_purchase_date,
    CASE WHEN brand_rank = 1 THEN TRUE ELSE FALSE END AS is_primary_brand,
    CASE WHEN total_brands > 1 THEN TRUE ELSE FALSE END AS is_multi_brand_customer
FROM ranked;
```

#### View 2：客戶主要品牌（簡化版）

```sql
-- 建立客戶主要品牌 View
-- 每位客戶只取一筆（購買次數最多的品牌）
CREATE OR REPLACE VIEW `b25h01-ragic.erp_backup.view_customer_primary_brand` AS
SELECT
    customer_code,
    brand_code AS primary_brand,
    order_count,
    total_amount,
    is_multi_brand_customer
FROM `b25h01-ragic.erp_backup.view_customer_brand`
WHERE is_primary_brand = TRUE;
```

### 8.5 查詢範例

#### 各品牌客戶數統計

```sql
SELECT
    brand_code,
    COUNT(DISTINCT customer_code) AS total_customers,
    COUNT(DISTINCT CASE WHEN is_primary_brand THEN customer_code END) AS primary_customers
FROM `erp_backup.view_customer_brand`
GROUP BY brand_code
ORDER BY total_customers DESC;
```

#### 找出跨品牌客戶

```sql
SELECT
    customer_code,
    COUNT(DISTINCT brand_code) AS brand_count,
    STRING_AGG(brand_code, ', ') AS brands
FROM `erp_backup.view_customer_brand`
GROUP BY customer_code
HAVING COUNT(DISTINCT brand_code) > 1
ORDER BY brand_count DESC;
```

#### 客戶完整資訊（含品牌）

```sql
SELECT
    c.customer_code,
    c.customer_name,
    c.phone,
    p.primary_brand,
    p.order_count,
    p.total_amount,
    p.is_multi_brand_customer
FROM `erp_backup.sheet_60_customer` c
LEFT JOIN `erp_backup.view_customer_primary_brand` p
    ON c.customer_code = p.customer_code;
```
