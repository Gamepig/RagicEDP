### 5.2 處理策略

| 策略 | 說明 |
|------|------|
| **只標記不修改** | 原始值完整保留，新增驗證標記欄位 |
| **建議修正值** | 可自動計算的提供 `_suggested_fix` 欄位 |
| **分類輸出** | 按規則 ID 分類輸出問題記錄 |
| **完整追溯** | 每筆標記包含規則 ID、檢測時間、錯誤描述 |

### 5.3 標記欄位設計

每筆有問題的記錄將新增以下欄位：

    {
      "rule_id": "CR-002",

      "field": "品牌編號",
      "original_value": "S27",
      "error_type": "missing_reference",
      "error_message": "品牌編號 S27 不存在於品牌表",

      "severity": "high",
      "flagged_at": "2025-12-26T12:00:00"
    }
  ],
  "_has_issues": true,
  "_issue_count": 1
}
