## 附錄：技術細節

### A. 分析方法

| 分析類型 | 方法 |
|---------|------|
| 空值率 | `IS NULL OR == ''` 統計 |
| 格式驗證 | 正則表達式匹配 |
| 外鍵完整性 | LEFT JOIN 找不存在的值 |
| 數值基線 | IQR（四分位距）方法 |
| 關聯規則 | GROUP BY 統計組合頻率 |
| 重複檢測 | GROUP BY + HAVING > 1 |

### B. 離群值判定標準

```
IQR = Q3 - Q1
下界 = Q1 - 1.5 × IQR
上界 = Q3 + 1.5 × IQR
離群值 = 值 < 下界 OR 值 > 上界
```
