## 6. 過濾資料分析

### 6.1 表50 過濾 127 筆的原因

從 Ragic API 抓取了 160 筆，其中 127 筆被清洗規則過濾：

| 可能原因 | 說明 |
|---------|------|
| **規則 C（未來日期）** | 歷史資料中存在異常的最後修改日期（如 2058、2059 年），這些記錄在每次增量備份時都會被抓取但被過濾 |

這 127 筆是 Ragic 系統中的異常資料，不是本次測試刪除的資料，過濾行為**符合預期**。

### 6.2 過濾規則說明

| 規則 | 適用表格 | 邏輯 |
|------|---------|------|
| 規則 A | 表99 | 訂單編號 + 商品編號 都為空 → 跳過 |
| 規則 B | 其他表 | 主鍵欄位為空 → 跳過 |
| 規則 C | 全部 | 最後修改日期 > 今天 → 跳過 |
