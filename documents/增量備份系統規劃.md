## 1. 需求概述

建立一組程式，自動完成以下流程：

```
┌─────────────────────────────────────────────────────────────────┐
│                      增量備份流程                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│   Step 1: 查詢 BigQuery                                          │
│   ┌─────────────────────────────────────────┐                   │
│   │  SELECT sheet_code,                     │                   │
│   │         MAX(last_modified_date) AS last │                   │
│   │  FROM erp_backup.ragic_data             │                   │
│   │  GROUP BY sheet_code                    │                   │
│   └─────────────────────────────────────────┘                   │
│                         ↓                                        │
│   Step 2: 從 Ragic 抓取新資料                                     │
│   ┌─────────────────────────────────────────┐                   │
│   │  GET /forms8/{sheet}                    │                   │
│   │  ?where={field_id},gt,{last_date}       │                   │
│   └─────────────────────────────────────────┘                   │
│                         ↓                                        │
│   Step 3: 轉換資料格式                                            │
│   ┌─────────────────────────────────────────┐                   │
│   │  中文欄位 → 英文欄位                      │                   │
│   │  日期格式標準化                           │                   │
│   └─────────────────────────────────────────┘                   │
│                         ↓                                        │
│   Step 4: 上傳至 BigQuery                                        │
│   ┌─────────────────────────────────────────┐                   │
│   │  MERGE INTO ragic_data                  │                   │
│   │  (Upsert by ragic_id + sheet_code)      │                   │
│   └─────────────────────────────────────────┘                   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 6. 執行方式

### 6.1 命令列介面

```bash
# 同步所有表格
uv run python scripts/incremental_sync.py all

# 同步指定表格
uv run python scripts/incremental_sync.py 50 99

# 查看各表最後同步時間
uv run python scripts/incremental_sync.py status

# 強制全量同步（忽略上次時間）
uv run python scripts/incremental_sync.py all --full

# 乾跑模式（只查詢不上傳）
uv run python scripts/incremental_sync.py all --dry-run
```

## 8. 錯誤處理

### 8.1 重試機制

| 錯誤類型 | 重試次數 | 間隔 |
|---------|---------|------|
| API 連線逾時 | 3 次 | 指數退避 (2^n 秒) |
| HTTP 429 限流 | 5 次 | 固定 60 秒 |
| BigQuery 暫時錯誤 | 3 次 | 指數退避 |

### 8.2 錯誤報告

- 部分失敗時繼續執行其他表格
- 最終報告所有失敗的表格和原因
- 選擇性發送 Email 通知
