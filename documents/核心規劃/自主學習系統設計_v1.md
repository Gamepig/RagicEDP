## 一、系統概述

### 1.1 設計目標

讓系統能在資料清理過程中：
1. **發現規則外的問題** - 現有規則無法評估的新狀況
2. **記錄問題** - 持久化存儲問題詳情與頻率
3. **分析問題** - 找出問題模式與影響範圍
4. **產生新規則** - 自動或半自動產生規則草稿
5. **形成閉環** - 持續演進規則庫

### 1.2 核心概念

規則應用時會產生三種結果：

| 結果 | 說明 | 處理方式 |
|------|------|---------|
| ✅ 通過 | 符合現有規則 | 跳過 |
| ❌ 違規 | 違反現有規則（已知異常） | 標記為異常 |
| ⚠️ **規則外** | 無法被現有規則評估 | **進入自主學習流程** |

---

## 二、規則外問題類型

| 類型代碼 | 名稱 | 描述 | 範例 |
|---------|------|------|------|
| **N1** | 新組合 | 品牌-促銷/通路組合從未出現 | CYT 首次使用 MK999 促銷 |
| **N2** | 模式不匹配 | 不符合任何已知模式但可能合法 | 新電話格式 +886-9xx-xxx-xxx |
| **N3** | 合理超界 | 超出 IQR 但可能是新業務 | 訂單金額異常高但有對應商品 |
| **N4** | 新值出現 | 出現新的品牌/通路/物流 | 新增物流商「順豐速運」 |
| **N5** | 跨欄位異常 | 多欄位組合出現異常模式 | 高單價商品配免運物流 |
| **N6** | 時序異常 | 時間邏輯不尋常但可能合理 | 非營業時間大量訂單 |

## 四、核心組件

### 4.1 問題偵測器 (OutOfRuleDetector)

```python
class OutOfRuleDetector:
    """偵測規則外的問題"""

    def __init__(self, rules: dict):
        self.rules = rules
        self.known_values = self._build_known_values()

    def detect(self, record: dict) -> list:
        """
        偵測規則外問題

        Returns:
            list of issues: [{type, fields, values, context}]
        """
        issues = []

        # N1: 新組合偵測
        issues.extend(self._detect_new_combinations(record))

        # N2: 模式不匹配偵測
        issues.extend(self._detect_pattern_mismatch(record))

        # N3: 合理超界偵測
        issues.extend(self._detect_reasonable_outlier(record))

        # N4: 新值偵測
        issues.extend(self._detect_new_values(record))

        return issues

    def _detect_new_combinations(self, record: dict) -> list:
        """偵測新的欄位組合"""
        issues = []
        brand = record.get('品牌編號')
        promotion = record.get('通路活動號碼1')

        if brand and promotion:
            brand_rules = self.rules.get('association_rules', {}).get(brand, {})
            allowed = brand_rules.get('allowed_promotions', [])

            # 如果品牌沒有任何規則，或促銷不在允許列表
            if not allowed:
                issues.append({
                    'type': 'N4',
                    'subtype': 'new_brand',
                    'fields': ['品牌編號'],
                    'values': [brand],
                    'context': f'新品牌 {brand} 首次出現'
                })
            elif promotion not in allowed:
                issues.append({
                    'type': 'N1',
                    'fields': ['品牌編號', '通路活動號碼1'],
                    'values': [brand, promotion],
                    'context': f'品牌 {brand} 首次使用促銷 {promotion}',
                    'existing_promotions': allowed
                })

        return issues

    def _detect_reasonable_outlier(self, record: dict) -> list:
        """偵測可能合理的超界值"""
        issues = []
        baselines = self.rules.get('numeric_baselines', {})

        for field, baseline in baselines.items():
            value = record.get(field)
            if value is None:
                continue

            try:
                value = float(value)
            except (TypeError, ValueError):
                continue

            upper = baseline.get('upper_bound', float('inf'))
            lower = baseline.get('lower_bound', float('-inf'))
            z_upper = baseline.get('z_upper', float('inf'))
            z_lower = baseline.get('z_lower', float('-inf'))

            # 超出 IQR 但在 3σ 內 - 可能合理的高/低值
            if (value > upper or value < lower) and (z_lower <= value <= z_upper):
                issues.append({
                    'type': 'N3',
                    'fields': [field],
                    'values': [value],
                    'context': f'{field} 值 {value} 超出 IQR 但在 3σ 內',
                    'bounds': {'iqr_upper': upper, 'iqr_lower': lower,
                              'z_upper': z_upper, 'z_lower': z_lower}
                })

        return issues
```

### 4.2 問題記錄器 (IssueLogger)

```python
import yaml
from datetime import datetime
from pathlib import Path

class IssueLogger:
    """問題記錄器 - 持久化存儲"""

    def __init__(self, issues_dir: str):
        self.issues_dir = Path(issues_dir)
        self.issues_dir.mkdir(parents=True, exist_ok=True)
        self.log_file = self.issues_dir / 'issue_log.yaml'
        self.issues = self._load_issues()
        self.issue_counter = {}

    def log(self, issue: dict, record_id: str) -> str:
        """
        記錄問題

        Args:
            issue: 問題資訊
            record_id: 記錄 ID

        Returns:
            issue_id: 問題編號
        """
        issue_key = self._generate_issue_key(issue)

        # 頻率統計
        if issue_key not in self.issue_counter:
            self.issue_counter[issue_key] = {
                'count': 0,
                'first_seen': datetime.now().isoformat(),
                'records': []
            }

        self.issue_counter[issue_key]['count'] += 1
        self.issue_counter[issue_key]['records'].append(record_id)
        self.issue_counter[issue_key]['last_seen'] = datetime.now().isoformat()

        # 只記錄新問題
        if self.issue_counter[issue_key]['count'] == 1:
            issue_id = f"ISS-{datetime.now().strftime('%Y%m%d')}-{len(self.issues) + 1:04d}"

            issue_record = {
                'id': issue_id,
                'key': issue_key,
                'type': issue['type'],
                'subtype': issue.get('subtype'),
                'detected_at': datetime.now().isoformat(),
                'first_record_id': record_id,
                'fields': issue['fields'],
                'values': issue['values'],
                'context': issue['context'],
                'frequency': 1,
                'status': 'pending'
            }

            self.issues.append(issue_record)
            return issue_id

        # 更新現有問題的頻率
        for existing in self.issues:
            if existing['key'] == issue_key:
                existing['frequency'] = self.issue_counter[issue_key]['count']
                return existing['id']

        return None

    def save(self):
        """保存到檔案"""
        with open(self.log_file, 'w', encoding='utf-8') as f:
            yaml.dump({
                'issues': self.issues,
                'statistics': self._generate_stats()
            }, f, allow_unicode=True, default_flow_style=False)

    def _generate_issue_key(self, issue: dict) -> str:
        return f"{issue['type']}:{':'.join(map(str, issue['values']))}"

    def _generate_stats(self) -> dict:
        type_counts = {}
        for issue in self.issues:
            t = issue['type']
            type_counts[t] = type_counts.get(t, 0) + 1

        return {
            'total_issues': len(self.issues),
            'by_type': type_counts,
            'pending': sum(1 for i in self.issues if i['status'] == 'pending'),
            'generated_at': datetime.now().isoformat()
        }
```

### 4.3 問題分析器 (IssueAnalyzer)

```python
class IssueAnalyzer:
    """問題分析器 - 批次分析問題模式"""

    AUTO_RULE_THRESHOLD = 10   # 出現 10 次以上自動產生規則
    OBSERVATION_THRESHOLD = 3  # 3 次以上加入觀察

    def analyze_batch(self, issues: list) -> list:
        """批次分析問題"""
        results = []
        by_type = self._group_by_type(issues)

        for issue_type, type_issues in by_type.items():
            if issue_type == 'N1':
                results.extend(self._analyze_new_combinations(type_issues))
            elif issue_type == 'N3':
                results.extend(self._analyze_reasonable_outliers(type_issues))
            elif issue_type == 'N4':
                results.extend(self._analyze_new_values(type_issues))

        return results

    def _analyze_new_combinations(self, issues: list) -> list:
        """分析新組合問題"""
        results = []

        promotion_brands = {}
        for issue in issues:
            if len(issue['values']) >= 2:
                brand, promotion = issue['values'][0], issue['values'][1]
                if promotion not in promotion_brands:
                    promotion_brands[promotion] = set()
                promotion_brands[promotion].add(brand)

        for issue in issues:
            brand, promotion = issue['values'][0], issue['values'][1]
            brands_using = promotion_brands.get(promotion, set())
            total_freq = sum(i['frequency'] for i in issues
                           if len(i['values']) >= 2 and i['values'][1] == promotion)

            result = {
                'issue_id': issue['id'],
                'analyzed_at': datetime.now().isoformat(),
                'pattern_found': len(brands_using) > 1,
                'total_occurrences': total_freq,
                'affected_brands': list(brands_using),
            }

            if total_freq >= self.AUTO_RULE_THRESHOLD:
                result['recommendation'] = 'add_rule'
                result['confidence'] = min(0.95, 0.7 + total_freq * 0.01)
                result['rule_suggestion'] = {
                    'action': 'add_allowed_promotion',
                    'brands': list(brands_using),
                    'promotion': promotion
                }
            elif total_freq >= self.OBSERVATION_THRESHOLD:
                result['recommendation'] = 'observe'
                result['confidence'] = 0.5
            else:
                result['recommendation'] = 'ignore'
                result['confidence'] = 0.3

            results.append(result)

        return results
```

### 4.4 規則產生器 (RuleGenerator)

```python
class RuleGenerator:
    """規則產生器 - 從分析結果產生規則草稿"""

    def generate_from_analysis(self, analysis_results: list) -> list:
        """從分析結果產生規則草稿"""
        pending_rules = []

        for result in analysis_results:
            if result.get('recommendation') not in ['add_rule', 'adjust_baseline']:
                continue

            rule = {
                'id': f"RULE-{datetime.now().strftime('%Y%m%d')}-{len(pending_rules)+1:04d}",
                'source_issue': result.get('issue_id'),
                'created_at': datetime.now().isoformat(),
                'status': 'pending_review',
                'confidence': result.get('confidence', 0.5),
                'evidence': {
                    'total_occurrences': result.get('total_occurrences'),
                    'affected_entities': result.get('affected_brands', [])
                }
            }

            suggestion = result.get('rule_suggestion', {})
            action = suggestion.get('action')

            if action == 'add_allowed_promotion':
                rule['rule_type'] = 'association'
                rule['action'] = 'add'
                rule['content'] = {
                    'brands': suggestion.get('brands', []),
                    'new_promotion': suggestion.get('promotion')
                }
                rule['description'] = f"允許品牌 {suggestion.get('brands')} 使用促銷 {suggestion.get('promotion')}"

            elif action == 'expand_iqr_bounds':
                rule['rule_type'] = 'numeric_baseline'
                rule['action'] = 'adjust'
                rule['content'] = {
                    'field': suggestion.get('field'),
                    'include_values': suggestion.get('new_values', [])
                }
                rule['description'] = f"擴展欄位 {suggestion.get('field')} 的合理範圍"

            pending_rules.append(rule)

        return pending_rules
```

### 4.5 規則管理器 (RuleManager)

```python
class RuleManager:
    """規則管理器 - 管理規則版本與合併"""

    def __init__(self, rules_dir: str):
        self.rules_dir = Path(rules_dir)
        self.pending_file = self.rules_dir / 'pending_rules.yaml'
        self.history_file = self.rules_dir / 'rule_history.yaml'

    def add_pending(self, rules: list):
        """加入待審核規則"""
        existing = self._load_pending()
        existing.extend(rules)

        with open(self.pending_file, 'w', encoding='utf-8') as f:
            yaml.dump({'pending_rules': existing}, f, allow_unicode=True)

    def approve_rule(self, rule_id: str) -> bool:
        """審核通過規則"""
        pending = self._load_pending()

        for rule in pending:
            if rule['id'] == rule_id:
                rule['status'] = 'approved'
                rule['approved_at'] = datetime.now().isoformat()

                self._merge_to_rules(rule)
                self._add_to_history(rule)
                pending.remove(rule)
                self._save_pending(pending)

                return True

        return False

    def auto_approve_high_confidence(self, threshold: float = 0.9):
        """自動審核高信心度規則"""
        pending = self._load_pending()

        for rule in pending[:]:
            if rule.get('confidence', 0) >= threshold:
                self.approve_rule(rule['id'])

    def _merge_to_rules(self, rule: dict):
        """合併規則到正式規則庫"""
        rule_type = rule.get('rule_type')

        if rule_type == 'association':
            rules_file = self.rules_dir / 'association_rules.yaml'
            with open(rules_file, 'r', encoding='utf-8') as f:
                rules = yaml.safe_load(f) or {}

            content = rule['content']
            for brand in content.get('brands', []):
                if brand not in rules:
                    rules[brand] = {'allowed_promotions': []}

                new_promo = content.get('new_promotion')
                if new_promo and new_promo not in rules[brand]['allowed_promotions']:
                    rules[brand]['allowed_promotions'].append(new_promo)

            with open(rules_file, 'w', encoding='utf-8') as f:
                yaml.dump(rules, f, allow_unicode=True)
```

## 七、審核策略

| 信心度 | 頻率閾值 | 審核方式 | 說明 |
|--------|---------|---------|------|
| ≥ 0.9 | ≥ 50 次 | **自動通過** | 高頻且多品牌使用 |
| 0.7-0.9 | 10-50 次 | **建議通過** | 人工確認後通過 |
| 0.5-0.7 | 3-10 次 | **人工審核** | 需人工判斷 |
| < 0.5 | < 3 次 | **持續觀察** | 暫不產生規則 |

## 八、關鍵設計決策

| 決策點 | 選項 | 決策 | 理由 |
|--------|------|------|------|
| **問題記錄頻率** | 每筆/批次 | 每筆 | 即時性高 |
| **分析觸發** | 即時/批次 | 每日批次 | 避免頻繁規則變更 |
| **審核模式** | 全自動/半自動/全人工 | 半自動 | 高信心度自動，其他人工 |
| **規則回滾** | 支援/不支援 | 支援 | 錯誤規則可撤銷 |
| **歷史保留** | 保留/不保留 | 保留 | 可追蹤規則演進 |

## 九、整合到分析計劃

本系統對應 [資料分析計劃_v1.md](./資料分析計劃_v1.md) 的 **Phase 5: 自主學習**

| 步驟 | 內容 | 方法 | 輸出 |
|------|------|------|------|
| 5.1 | 應用規則檢查新資料 | CleaningRuleApplier | violations + out_of_rule |
