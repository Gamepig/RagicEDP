04 資料表完整欄位清單

GA4 materialized tables

表 日期欄位 完整欄位
mat_ga4_daily_traffic date brand_code, date, sessions, users, new_users, engaged_sessions, engaged_rate, avg_engagement_sec, purchasers, cvr
欄位格式：
  • date：STRING (YYYYMMDD)
  • brand_code：STRING，對應 erp_backup.brand_code
  • sessions：INTEGER，GA4 sessions
  • users：INTEGER，唯一用戶數
  • new_users：INTEGER，首次造訪用戶
  • engaged_sessions：INTEGER，參與互動的 sessions
  • engaged_rate：FLOAT (0-1)，engaged_sessions / sessions
  • avg_engagement_sec：FLOAT，平均互動秒數
  • purchasers：INTEGER，購買用戶數
  • cvr：FLOAT (0-1)，purchasers / sessions
mat_ga4_source_daily event_date brand_code, event_date, source, medium, sessions, users, first_visit_count, engaged_rate, avg_engagement_sec, purchasers, cvr
欄位格式：
  • event_date：STRING (YYYYMMDD)，AI 必用此欄位
  • source：STRING，流量來源 (google, facebook, email 等)
  • medium：STRING，流量媒介 (cpc, cpm, organic 等)
  • sessions：INTEGER，該來源媒介的造訪次數
  • users：INTEGER，唯一用戶數
  • first_visit_count：INTEGER，該來源的首次造訪數
  • cvr：FLOAT (0-1)，購買轉換率
mat_ga4_campaign_daily date brand_code, date, source, medium, campaign_name, sessions, users, new_visitors, returning_visitors, engaged_rate, avg_engagement_sec, purchasers, cvr
欄位格式：
  • date：STRING (YYYYMMDD)
  • campaign_name：STRING，廣告活動名稱
  • new_visitors：INTEGER，新訪問者數
  • returning_visitors：INTEGER，回訪者數
mat_ga4_sessions event_date brand_code, event_date, ga_session_id, user_pseudo_id, ga_session_number, source, medium, campaign, device_category, landing_page, session_engaged, total_engagement_time_msec, purchase_count, event_count
欄位格式：
  • ga_session_id：STRING，GA4 session ID
  • user_pseudo_id：STRING，匿名用戶 ID
  • ga_session_number：INTEGER，用戶第 N 個 session
  • device_category：STRING (mobile/desktop/tablet)
  • landing_page：STRING，着陸頁面
  • session_engaged：BOOLEAN/Y/N，是否為參與式 session
  • total_engagement_time_msec：INTEGER，總互動毫秒數
  • purchase_count：INTEGER，該 session 購買次數
  • event_count：INTEGER，session 內事件數
mat_ga4_ecommerce event_date brand_code, event_date, event_name, user_pseudo_id, transaction_id, event_value, currency, customer_type, item_id, item_name, item_brand, item_category, item_price, item_quantity, item_revenue
欄位格式：
  • event_name：STRING (purchase, add_to_cart, begin_checkout 等)
  • user_pseudo_id：STRING，匿名用戶 ID
  • transaction_id：STRING，交易 ID
  • event_value：NUMERIC，事件價值
  • currency：STRING，幣別
  • customer_type：STRING，用戶類型
  • item_id：STRING，商品 ID
  • item_name：STRING，商品名稱
  • item_brand：STRING，商品品牌
  • item_category：STRING，商品類別
  • item_price：NUMERIC，商品價格
  • item_quantity：INTEGER，商品數量
  • item_revenue：NUMERIC，商品收入
mat_ga4_flat_events event_date brand_code, event_date, event_timestamp, event_name, user_pseudo_id, stream_id, platform, device_category, device_os, geo_country, geo_city, traffic_source, traffic_medium, traffic_campaign, utm_campaign, ga_session_id, ga_session_number, session_engaged, engagement_time_msec, page_location, page_title, event_value, currency, transaction_id, customer_type
欄位格式：
  • event_timestamp：INTEGER (微秒級)，BigQuery 內部為微秒需除 1000000
  • page_location：STRING，事件發生頁面 URL
  • stream_id：STRING，資料流 ID
  • platform：STRING，平台 (web/android/ios)
  • device_category：STRING (mobile/desktop/tablet)
  • device_os：STRING，作業系統
  • geo_country：STRING，國家
  • geo_city：STRING，城市
  • traffic_source：STRING，流量來源
  • traffic_medium：STRING，流量媒介
  • traffic_campaign：STRING，流量活動
  • utm_campaign：STRING，UTM 活動
  • ga_session_number：INTEGER，用戶第 N 個 session
  • session_engaged：STRING，是否參與
  • engagement_time_msec：INTEGER，互動毫秒數
  • page_title：STRING，頁面標題

ERP 核心 View

表 用途 完整欄位
view_order_customer 訂單客戶檢視 ragic_id, order_code, order_date, order_amount, status, backup_time, cleaning_status, customer_code, order_amount_with_shipping
欄位格式：
  • order_date：DATE，訂單日期 (YYYY-MM-DD)
  • status：STRING，訂單狀態 ('toggle-on' = 有效訂單)
  • order_amount：NUMERIC，不含運費金額
  • order_amount_with_shipping：NUMERIC，含運費總金額
  • backup_time：TIMESTAMP，備份時間
  • cleaning_status：STRING，清洗狀態
ls_v_orders_ext 訂單擴展檢視 order_code, order_date, customer_code, customer_name, brand_code, brand_name, order_amount, order_amount_with_shipping, status, postal_code, city, district, platform_order_no, invoice_flag, order_created_at
欄位格式：
  • postal_code：STRING，郵遞區號
  • city：STRING，城市
  • district：STRING，地區
  • platform_order_no：STRING，平台訂單號
  • invoice_flag：STRING，發票狀態
  • order_created_at：TIMESTAMP，訂單建立時間
ls_v_order_lines 訂單明細檢視 order_code, order_date, customer_code, customer_name, product_code, product_name, brand_code, brand_name, product_series, product_structure, quantity, unit_price, subtotal, order_amount, line_created_at, order_created_at
欄位格式：
  • quantity：INTEGER，訂購數量
  • unit_price：NUMERIC，單價
  • subtotal：NUMERIC，明細小計
  • product_series：STRING，商品系列
  • product_structure：STRING，商品結構
  • line_created_at：TIMESTAMP，明細建立時間
  • order_created_at：TIMESTAMP，訂單建立時間
ls_v_order_lines_ext 明細擴展檢視 order_code, order_date, customer_code, customer_name, product_code, product_name, brand_code, brand_name, product_series, product_structure, quantity, unit_price, subtotal, order_amount, status, channel_code, channel_name, payment_method, payment_code, payment_name, logistics_code, logistics_name, logistics_vendor, logistics_temp_layer, shipping_income, amount_paid, amount_with_shipping, cod_flag, desired_delivery_timeslot, channel_campaign_no1, channel_campaign_no2, channel_campaign_no3, channel_campaign_no4, channel_campaign_no5, line_created_at, order_created_at
欄位格式：
  • quantity：INTEGER，訂購數量
  • unit_price：NUMERIC，單價
  • subtotal：NUMERIC，明細小計
  • amount_paid：NUMERIC，實付金額
  • amount_with_shipping：NUMERIC，含運實收
  • shipping_income：NUMERIC，運費收入
  • logistics_vendor：STRING，物流商
  • logistics_temp_layer：STRING，物流溫層
  • cod_flag：BOOLEAN，貨到付款標記
  • channel_campaign_no1-5：STRING，通路活動編號
  • line_created_at：TIMESTAMP，明細建立時間
  • order_created_at：TIMESTAMP，訂單建立時間
erp_daily_sales 每日品牌彙總 brand_code, date, revenue, orders, customers, aov, new_customers
欄位格式：
  • revenue：NUMERIC，含運營收總額
  • orders：INTEGER，訂單數
  • customers：INTEGER，客戶數
  • aov：NUMERIC，平均訂單金額 (revenue / orders)
  • new_customers：INTEGER，新客戶數
ls_p3_rfm 客戶 RFM 分析 brand_code, brand_name, customer_code, customer_name, first_order_date, last_order_date, recency_days, frequency, monetary, avg_order_value
欄位格式：
  • recency_days：INTEGER，最近購買天數
  • frequency：INTEGER，購買次數
  • monetary：NUMERIC，總消費金額
  • avg_order_value：NUMERIC，平均訂單金額
  • first_order_date：DATE，首次訂單日期
  • last_order_date：DATE，最後訂單日期

06 AI 查詢限制

  • GA4 source/medium 必用 mat_ga4_source_daily.event_date
  • ERP 品牌查詢用 view_order_customer 或 erp_daily_sales
  • 營收預設含運，使用 order_amount_with_shipping
  • GA4-ERP 交叉分析 View：
    • vw_ls_ga4_source_sales_daily：GA4 source/medium + ERP 營收
