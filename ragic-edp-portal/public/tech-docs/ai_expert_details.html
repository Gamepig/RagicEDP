02 核心程式詳細說明

檔案 作用 詳細說明
src/app/api/ai/chat/route.ts AI Chat API 端點 接收 SSE 串流請求，驗證登入、授權、訊息長度與 session 限制，呼叫 intent-router 進行意圖分類，呼叫 sql-generator 產生 SQL，執行查詢後回傳 token/progress/trace/done 事件
src/lib/ai/intent-router.ts 意圖分類 classifyIntent() 根據 prompt 判斷 simple_answer、query_database、generate_chart、deep_research、query_ragic 等類型。使用關鍵字與語境匹配
src/lib/ai/sql-generator.ts SQL 產生器 讀取 schema cache 與 data catalog，套用 Vertex AI 生成 SQL，支援 deterministic fallback
src/lib/ai/sql-fallbacks.ts 備用邏輯 固定 SQL 模板避免常見問題完全依賴 LLM：getBrandShareFallbackSql()、buildDeterministicGa4SourceSql()、buildDeterministicWeekendWeekdayAovSql()、buildDeterministicGa4RagicDailyDiffSql()
src/lib/ai/sql-safety.ts SQL 安全檢查 validateSql() 禁止 INSERT、UPDATE、DELETE、DROP、CREATE、ALTER、TRUNCATE、多重語句、沒有 FROM 的 SQL、結尾停在 WHERE/GROUP BY。自動補 LIMIT 200
src/lib/ai/data-catalog.ts 資料白名單 定義 AI 可使用的表與欄位，防止發明不存在的欄位
src/lib/ai/schema-cache.ts BigQuery schema cache 快取資料表結構，加速 SQL 產生
src/lib/ai/query-context-resolver.ts 對話上下文解析 resolveQueryContext() 與 resolveDateRangeFromText() 解析品牌、日期、通路與前文延續條件
src/lib/ai/ragic-query-gen.ts Ragic 查詢產生 generateRagicQuery() 產生 Ragic where 條件，支援日期區間強制與上下文繼承
src/lib/ai/sql-business-rules.ts 商業 SQL 規則 applyBusinessSqlRules() 修正口徑：營收預設含運、明細預設含運、預設排除取消/停用訂單
src/lib/ai/vertex-client.ts Vertex AI 客戶端 封裝 Vertex AI 請求，處理 SSE 串流回應
src/lib/ai/expert-prompt.ts 系統提示詞 定義 AI 行為規則與輸出格式

03 SQL 產生規則

類型 規則
營收查詢 預設 LOWER(status)='toggle-on'，含運口徑 order_amount_with_shipping
GA4 source/medium 禁用 date 欄位，用 event_date
品牌查詢 JOIN 用 brand_code，顯示用 brand_name
表白名單 見 data-catalog.ts 完整列表

04 Fallback 機制

  1. SQL 執行失敗 → 嘗試簡化查詢
  2. 資料為空 → 提供建議或替代日期
  3. 欄位錯誤 → 使用類似欄位或建議修正
