02 架構圖

[GA4] → BigQuery Materialized Tables
                     ↓
[Ragic ERP] → Cloud Functions (backup) → BigQuery ERP Tables
                     ↓
        [Looker Studio] ← BigQuery Views
              ↑
        [Portal] ← AI Agent ← SQL Generator

資料流程：

  1. Ragic → BigQuery：Cloud Functions 擷取 Ragic ERP 資料，存入 BigQuery
  2. GA4 → BigQuery：Materialized tables 系列 (mat_ga4_*)
  3. 彙總/清洗：app/etl/ 星狀模型 ETL，app/cleaning/ 清洗引擎
  4. 展示層：Portal (Next.js)、Looker Studio 讀取 BigQuery Views

05 資料流程詳細

Ragic → BigQuery

1. Ragic API (ap6.ragic.com/grefun)
   ↓
2. Cloud Functions backup-erp-incremental
   - 擷取 Sheet 10,20,30,40,41,50,60,70,80,99
   - 增量判斷：last_modified + 回補視窗 (ORDER_RECONCILE_WINDOW_DAYS)
   - Tombstone 標記已不存在訂單
   ↓
3. BigQuery erp_backup 資料集
   - sheet_10_brand, sheet_20_channel ... sheet_99_order_detail

AI 問答流程

1. 使用者提問 → api/ai/chat/route.ts
   ↓
2. classifyIntent() 判斷意圖類型
   ↓
3. resolveQueryContext() 解析上下文
   ↓
4. SQL 產生 → validateSql() 安全檢查
   ↓
5. SSE 串流回傳
